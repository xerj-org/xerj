XERJ ships one ~36 MB binary. What varies by vertical is the deployment topology, the compliance matrix, and the audit expectations. The engine is identical. The runbooks are shared.

SELF-HOSTED
Your cloud · your VPC · your metal · your SCIF. No outbound data path unless you configure one. No vendor in your data path.
DROP-IN ES 8.13
Same client libraries. Same query DSL. Same _bulk API. Your existing ingest pipelines and dashboards work unchanged.
PER-QUERY AUDIT
Every retrieval produces a structured explain-plan — principal, query, rows, cost. Queryable as a regular index. Model-risk evidence for free.
BYOK
Customer-managed keys via AWS KMS · GCP KMS · Azure Key Vault · HashiCorp Vault · Thales Luna HSM. No XERJ-side plaintext access.
OFFLINE DEPLOYMENT
Standard binary · offline lexical mode · operator-staged archive + adjacent .sha256 integrity only · optional local model · no runtime telemetry/update/license calls. See the deployment recipe.
