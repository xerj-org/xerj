Search for AI agents.

A new way for AI to search data: give your coding agent one prompt, and it answers from a local index, citing the file and line.

Install XERJ (docs: https://xerj.org/llms.txt), index this project's sources, and set up reference coding: clone and index the open-source repos closest to what we're building, and search how they solved a problem before writing code.

Three ways in

Ask a library, search your files, or connect over MCP

01 · Ask a library

A library's source at a pinned commit, without cloning. One signed pack, pulled once.

xerj "how does zstd pick a window size"
xerj ask --def ZSTD_compressBound
xerj ask reference → 02 · Search your files

Code, PDF, DOCX, SQLite, CSV, mail and logs in one local index. Nothing leaves the machine.

xerj --insecure --data-dir ~/xerj-data &
xerj autoindex ~/my-project
xerj search "how do we rotate the WAL segment"

Before you rely on it

When XERJ does not help

  • Libraries the model already knows. There retrieval only adds cost (case study).

  • Lexical by default. The built-in embedder is feature hashing; start the node with --embed-mode neural for a neural model.

  • One node. No replication or failover. Choose Elasticsearch if you need a cluster or steady read p99 under heavy concurrent writes (benchmarks).

  • --insecure is for one user on one machine. It turns off TLS and API keys (security model).
