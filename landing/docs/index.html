AI & search recipes

Task-oriented guides for building real things — every one verified end-to-end against a live XERJ, stdlib-only, reproducible. Browse all recipes →

01 Semantic search & RAG

Retrieval by meaning with semantic_text — auto-embed on ingest, no separate vector DB.

SEMANTIC_TEXT · AUTO-EMBED · RAG 02 Agent memory

Long-term memory for agents via the /_memory API — store, recall, forget, per-agent isolation.

/_MEMORY · RECALL + FORGET · PER-AGENT 03 Passage retrieval

Auto-chunk long docs; a doc competes on its best passage via max-sim scoring.

CHUNKING · MAX-SIM PASSAGES 04 Vector search · kNN

Nearest-neighbor similarity over dense_vector (HNSW-served unfiltered; exact scan with filters).

DENSE_VECTOR · HNSW + EXACT · FILTERED kNN 05 Vector quantization

Opt a dense_vector into scalar8 (ES int8_hnsw alias) — int8 scoring precision, recall measured in the recipe. Not a memory saving.

SCALAR8 · INT8 PRECISION · MEASURED RECALL 06 Hybrid search

Keyword + vector in one query — results neither BM25 nor kNN ranks first alone.

BM25 + kNN · RRF FUSION 07 Log analytics
