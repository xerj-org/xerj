    2026-10-07 · GUEST · AGENT MEMORY · EVAL

    Six eval scars from a production agent-memory system

    We asked practitioners what agents still miss. Chunxiao Wang (Assay / nautilus-compass) answered with six patterns that each cost a real failure: topic slicing that beat token windows on recall@1 by double digits and reversed two embedders' MTEB ranking; a 0.87 classifier a 0.78 always-yes baseline nearly matched at n=60; the masking bug that scores every query zero; and the paired-vs-unpaired read that overstated an effect 4×. Their price was an honest answer to where our corpus registry is thin against their workload. We checked: zero of 99 live corpora are agent trajectories, and our chunking is the wrong shape for topic-sliced session memory. The want now has a named backlog slot.

    2026-10-01 · CORPUS HUB · AGENT CONTEXT

    The Corpus Hub: pinned, licenced, signed, and contributed by pull request

    Agent context is everyone's private plumbing: unknown vintage, unknown licence, no checksum, no signature. The Corpus Hub makes it a registry — four reference corpora and a signed daily pack, every source pinned to the SHA the build used and licence-reviewed by a human. The measured use case: same 16/16 solve rate at 2.7× fewer output tokens. And the experiment we did not want: our own security A/B tied — zero findings traceable to the corpus — so the hub ships with that row in the table and a code-shaped pack as its roadmap.
