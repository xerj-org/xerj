# XERJ

**XERJ: موتور جست‌وجو برای عامل‌های هوش مصنوعی (AI Agents).** رویکردی نوین برای جست‌وجوی داده‌ها توسط هوش مصنوعی؛ یک فایل اجرایی محلی مبتنی بر Rust که کدها، مستندات، مشخصات فنی و گزارش‌های سیستم (Logs) شما را ایندکس می‌کند. همچنین با استفاده از بسته‌های Corpus Hub، امکان دسترسی به مجموعه‌داده‌های آماده را فراهم می‌کند و نتایج جست‌وجو را همراه با ارجاعات و منابع (Citations) ارائه می‌دهد.

**موتور جست‌وجوی Local-first و سرور MCP برای عامل‌های هوش مصنوعی.** یک فایل اجرایی مبتنی بر Rust که کدها، مستندات، گزارش‌های سیستم، فایل‌های JSONL و CSV و اسناد PDF را ایندکس می‌کند و قابلیت‌های جست‌وجوی متنی BM25، جست‌وجوی برداری (Vector Search)، جست‌وجوی ترکیبی (Hybrid Search)، جست‌وجوی کد و حافظه عامل‌های هوش مصنوعی را ارائه می‌دهد. تمام این قابلیت‌ها از طریق یک API سازگار با Elasticsearch در دسترس هستند.

XERJ با ابزارهایی مانند Claude Code، Cursor و هر کلاینت سازگار با MCP کار می‌کند.
