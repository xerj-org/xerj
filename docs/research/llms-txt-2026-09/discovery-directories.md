## Patterns observed

1. SKILL-FIRST PROMPT INSIDE llms.txt, with capability branching. AI SDK: "If you can fetch URLs, search the docs first: … https://ai-sdk.dev/api/search-docs?q=your+query" then "If you are working inside a local coding project with filesystem access, install the AI SDK skill first: npx skills add vercel/ai … Then follow the skill instructions before changing code." — https://ai-sdk.dev/llms.txt. Composio adds the failure ladder: "If it is missing, install it … requesting approval if your host requires it. If skills are unsupported or installation fails, use the documentation lin[ks]" — https://docs.composio.dev/llms.txt. I infer this is the direct fix for XERJ's 'doc assumes a shell' finding: branch on (can fetch URLs) / (has filesystem+shell) / (MCP-only).

2. ONE-LINE 'PASTE THIS INTO YOUR AGENT' PROMPT. Browserbase: "Copy this prompt into your agent to get started: Read https://browserbase.com/SKILL.md to set up Browserbase" — https://docs.browserbase.com/welcome/quickstarts/skills.md (SKILL.md at https://www.browserbase.com/SKILL.md, 200). 3. AGENT-ADDRESSED SETUP SCRIPT with explicit 'don't run the human sections' and a scripted hand-off to the human. Algolia: "This section is the complete setup: run only the commands below.
