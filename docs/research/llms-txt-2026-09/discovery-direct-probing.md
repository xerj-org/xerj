## Patterns observed

1. REPO ROOTS: 0 of 140 GitHub repos serve llms.txt, llms-install.md or SKILL.md at HEAD root. AGENTS.md and/or CLAUDE.md exist in ~60, and every one sampled is contributor-facing (build/test/PR rules), e.g. https://raw.githubusercontent.com/elastic/elasticsearch/HEAD/AGENTS.md (16.6 KB), https://raw.githubusercontent.com/All-Hands-AI/OpenHands/HEAD/AGENTS.md (117.9 KB), https://raw.githubusercontent.com/ollama/ollama/HEAD/AGENTS.md ('## Building'). ~30 repos use a one-line pointer: CLAUDE.md = '@AGENTS.md' or symlink text 'AGENTS.md' (https://raw.githubusercontent.com/supabase/supabase/HEAD/CLAUDE.md, https://raw.githubusercontent.com/prisma/prisma/HEAD/CLAUDE.md); the reverse direction exists too (https://raw.githubusercontent.com/oven-sh/bun/HEAD/AGENTS.md = 'CLAUDE.md'); exotic targets: Zed both files = '.rules', HF transformers = '.ai/AGENTS.md', Langfuse AGENTS.md = '.agents/AGENTS.md', ClickHouse AGENTS.md = '.claude/CLAUDE.md'. INFER: repo-root agent files are not where any peer puts user-facing install prompts.

2. NO REPORT-BACK ASK ANYWHERE: across every probed llms.txt, llms-full.txt, agents.md and SKILL.md, no project asks the agent to file a report, open a PR, or send feedback after use. A grep of all llms.txt indexes for 'report back|field report|let us know|tell us|send feedback|open an issue' returns only Contributing/Community links. The only feedback channels seen: a docs-MCP tool (https://docs.tavily.com/agents.md: 'The documentation server also provides a tool for submitting documentation feedback.'), telemetry pages (https://docs.crewai.com/llms.txt lists '[Telemetry]'), and install-count badges (https://github.com/neondatabase/agent-skills uses shieldcn.dev/skills/installs badges via skills.sh).
